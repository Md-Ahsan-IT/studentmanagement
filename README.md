# Student Management System

A complete Student Management System built with Python OOP principles and Streamlit for the user interface.

## 🌐 Live Demo
[Click here to use the Live App](https://studentmanagement-8ctsmkbjy5rnfsukbekyux.streamlit.app/)

## 📋 Features
- ✅ **Add New Students** - With automatic ID generation
- ✅ **Update Student Information** - Modify existing records
- ✅ **Delete Students** - Remove students with confirmation
- ✅ **View All Students** - Table format with statistics
- ✅ **Search & Filter** - Search by name/email, filter by grade, age, performance
- ✅ **Input Validation** - Comprehensive validation for all fields
- ✅ **JSON Data Storage** - Persistent data storage
- ✅ **Responsive UI** - Clean Streamlit interface

## 🛠️ Technologies Used
- **Python** - Core programming language
- **Streamlit** - Web application framework
- **Pandas** - Data manipulation and display
- **JSON** - Data storage and persistence

## 📁 Project Structure
studentmanagement/
├── student_app.py # Main application file
├── requirements.txt # Project dependencies
├── README.md # Project documentation
└── students.json # Data storage (auto-created)

## 🚀 Local Installation

1. **Clone the repository**
```bash
git clone https://github.com/Md-Ahsan-IT/studentmanagement.git
cd studentmanagement

2.Install dependencies
pip install -r requirements.txt

3.Run the application
streamlit run student_app.py

4.Open your browser and go to http://localhost:8501

💻 Usage
Add Student: Fill the form to add new students with automatic ID generation

View All Students: See all students in a table format with statistics

Update Student: Select a student and modify their information

Delete Student: Remove students with confirmation dialog

Search & Filter: Find students using various criteria

🔧 Core Functionality
CRUD Operations: Complete Create, Read, Update, Delete functionality

Data Validation: Email validation, age range checking, grade format validation

Search Features: Real-time search by name and email

Filter Options: Filter by grade, age range, and performance

Data Persistence: Automatic save/load from JSON file
